description: Apply when implementing features, fixing bugs, or changing application behavior.

Consider testability during implementation.

Identify:

- Critical paths
- Edge cases
- Failure scenarios

Recommend:

- Unit tests
- Integration tests
- End-to-end tests

Test:

- Happy path
- Invalid input
- Error handling
- Boundary conditions
- Regression risk

Do not generate excessive tests for trivial code.

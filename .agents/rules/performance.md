Optimize only where it provides measurable value.

Prioritize:

- Small bundles
- Lazy loading
- Efficient rendering
- Low memory usage
- Minimal allocations
- Efficient algorithms
- Efficient database queries
- Proper indexing
- Minimize network requests

Avoid:

- Premature optimization
- Micro-optimizations
- Readability loss

Measure before recommending major optimizations.

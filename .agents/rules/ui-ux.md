Design interfaces that maximize usability.

Prioritize:

- Simplicity
- Accessibility
- Readability
- Responsive layouts
- Consistent spacing
- Clear hierarchy
- Minimal cognitive load

Every screen should have:

- One primary action
- Clear navigation
- Predictable interactions

Avoid:

- Unnecessary dialogs
- Hidden functionality
- Excessive animations
- Visual clutter

Use animations only to improve understanding.

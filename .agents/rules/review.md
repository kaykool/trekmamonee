Before returning code perform a review.

Verify:

- Correctness
- Readability
- Error handling
- Edge cases
- Performance
- Security
- Accessibility where applicable
- Consistency
- Dependency impact

Identify:

- Dead code
- Duplicate logic
- Unnecessary abstraction
- Potential bugs
- Simplification opportunities

Recommend improvements when meaningful.

Do not fabricate technical information.

When using frameworks, libraries, SDKs, CLIs, or APIs:

- Use Context7 whenever documentation is available.
- Use only documented, stable APIs.
- Assume the latest stable version unless another version is explicitly provided.
- Never invent functions, methods, configuration options, CLI commands, package names, or framework features.

If documentation cannot confirm an implementation:

- State that the information is uncertain.
- Explain why.
- Recommend verification instead of guessing.

Separate:

- Verified facts
- Reasonable assumptions
- Unknown information

Never present assumptions as facts.

If multiple documented solutions exist, compare them briefly and recommend one based on simplicity, maintainability, and project requirements.

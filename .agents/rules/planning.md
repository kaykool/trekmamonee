Before writing code:

1. Identify the objective and expected outcome.
2. Determine whether enough information exists to complete the task correctly.
3. If critical information is missing, ask only the minimum necessary questions.
4. Identify technical constraints, dependencies, and affected components.
5. Estimate the appropriate project scale:
   - Prototype
   - Personal application
   - Small production app
   - Large production system
6. Choose the simplest architecture that satisfies the current scale.
7. Avoid introducing abstractions that are not immediately justified.
8. Break large tasks into small implementation steps.
9. Preserve the existing architecture unless there is a measurable improvement.

Do not generate large amounts of code until the implementation approach is clear.
